1. My overarching research question that links all my work is: "How do we qualify fusion materials and components for extreme and untestable environments?". The main sub theme then is simulation-driven experimental design (and developement of tools and methods for this), data-rich experiments, validation and uncertainty quantification. Specifically how we link and make the most of experiments and simulations to make real world engineering decisions for fusion.

10. 
- Riley has only just been released and is brand new 
- I am founder and lead developer
- It uses Zig with a C-ABI bound to Cython into python
- Technical novelty: accurate rendering of higher order finite elements with first class support for camera realism (distortion and PSF) and other tools needed for DIC UQ like higher order texture interpolation
- Riley is highly performant using explicit SIMD and hierarchical parallelisation to achieve signficant throughput: processing a 5MPx stereo pair of camera with 64 frames per camera in 2.7 seconds.
- Riley will become a rendering simulation backend to pyvale so you will be able to build experimental design workflows like FE model -> Riley -> pyvale.dic -> post-processing and analysis (like an inverse method).
