# 📑 OpenOffice Copy Template: Grade E

**Role Title:** Computational Performance Engineer

**Division / Function:** Research & Development / Fusion Technology

**Grade:** Grade E

**Reports to:** Senior / Lead / Principal Computational Performance Engineer

**Skill Type:** Technical Specialist

**Line Manager:** No

### Overall Purpose

This role exists to develop and maintain high-performance compiled calculation cores and accessible Python interfaces that support simulation-driven experimental design and sensor simulation for Uncertainty Quantification (UQ) across fusion engineering programmes. It aims to translate physics-based sensor models into efficient code, enabling experimentalists to run rapid Verification, Validation, and Uncertainty Quantification (VVUQ) pipelines seamlessly. Without this role, workflows would be bottlenecked by unoptimised software abstractions, delaying critical virtual testing cycles and sensor deployment optimisations.

### Accountabilities

* **Develop Performant Code:** Write, test, and document memory-safe, hardware-aware computational code using compiled systems programming languages (C, Zig, or C++) within prescribed parameters to optimise core algorithmic execution speeds.


* **Implement Python Interfaces:** Create and deploy robust, low-overhead Python bindings utilising frameworks like `nanobind`, `pybind11`, or `Cython` to expose fast compiled cores directly to experimentalists.


* **Execute Verification Tests:** Apply basic analytical techniques to execute assigned verification and validation protocols, conducting code-level tests such as solver error analysis and simulated sensor footprint checks.


* **Apply Performance Principles:** Demonstrate foundational knowledge of performance-aware programming, including an initial understanding of data-oriented design, cache/memory coherence, and shared-memory parallel multi-threading to write code that respects underlying Central Processing Unit (CPU) hardware architectures.


* **Contribute to Research Outputs:** Prepare accurate records, write technical codebase documentation, and contribute sections or data plots to peer-reviewed journal articles, technical reports, and collaborative research outputs.


* **Manage Individual Workflow:** Function independently with minimal work direction on day-to-day tasks, proactively prioritising work activities while escalating highly complex, non-standard technical anomalies to senior colleagues.



### Specific Qualifications/Experience

* **Minimum Qualifications:** Degree-level qualification in Engineering, Computer Science, Mathematics, or a highly quantitative physical science discipline, or an entry-level post-Doctor of Philosophy (PhD), or equivalent industrial experience.


* **Technical Know-How:** Demonstrable practical experience in systems programming languages (C, C++, or Zig) alongside a developing specialist knowledge of Python packaging, deployment, and performance strategy.


* **Methodological Awareness:** Familiarity with performance-aware programming concepts, data-oriented design patterns, and baseline Verification, Validation, and Uncertainty Quantification (VVUQ) principles for sensor systems.


* **Soft Skills:** Good communication skills with the ability to explain technical execution details both verbally and in writing, strong problem-solving initiative, and an adaptable approach to collaborative team environments.



### Additional Duties

* Complete specialised organisational training modules regarding local computing infrastructure, software assurance standards, and matrix project delivery frameworks.


* Provide informal guidance, onboarding support, or technical task induction to students, academic placements, or less experienced colleagues when requested.


* Adhere to and promote all organisational values, equity, diversity, and inclusion directives, and behaviours supporting safety, health, and welfare across all computing environments.

**Division / Function:** Research & Development / Fusion Technology

**Grade:** Grade F

**Reports to:** Senior / Lead / Principal Computational Performance Engineer

**Skill Type:** Technical Specialist

**Line Manager:** No (Task Supervision Only)

### Overall Purpose

This role exists to analyse, optimise, and engineer high-performance software utilities that underpin simulation-driven experimental design and sensor-based Uncertainty Quantification (UQ) frameworks. It aims to maximise single-threaded and vectorised execution speeds on modern hardware architectures, ensuring math-heavy validation and sensor simulation algorithms run close to silicon limits. Without this role, complex experimental parameter studies and multi-sensor uncertainty sweeps would remain computationally intractable due to inefficient memory utilisation and sub-optimal hardware vectorisation.

### Accountabilities

* **Optimise Hardware Execution:** Apply intermediate proficiency in performance-aware programming, actively troubleshooting and optimising software blocks through data-oriented design, cache/memory coherence mechanisms, explicit Single Instruction Multiple Data (SIMD) execution, and shared-memory parallel multi-threading.


* **Implement VVUQ Protocols:** Adapt and engineer moderately complex mathematical formulations (such as sensor physics algorithms or inverse-mapped data routines) into high-performance compiled pipelines from first principles to drive robust Verification, Validation, and Uncertainty Quantification (VVUQ) studies.


* **Evaluate Alternative Approaches:** Execute advanced verification profiling sweeps, including numerical convergence tracking and sampling boundary metrics, to evaluate alternative computing approaches based on technical merit.


* **Author Research Publications:** Co-author peer-reviewed journal papers and generate well-structured reports describing novel performance frameworks, open-source software packages, and sensor simulation verification methodologies.


* **Supervise Task Packages:** Coordinate discrete work packages and set technical tasks for less experienced team members or external contractors, conducting routine technical reviews of deliverables against project goals.


* **Exercise Professional Judgement:** Select appropriate professional principles, tools, and methodologies to address varying, non-standard computational challenges where the required scientific outcome is defined but the delivery path requires independent interpretation.



### Specific Qualifications/Experience

* **Minimum Qualifications:** Degree-level qualification with demonstrable relevant experience, or a Doctor of Philosophy (PhD) in a relevant computational or engineering field, or equivalent substantial industrial experience.


* **Technical Know-How:** Advanced knowledge of compiled systems programming platforms (C, C++, or Zig), coupled with a recognised internal specialisation in performance profiling, memory alignment, and low-overhead Python binding infrastructure including Application Binary Interfaces (ABI) and Foreign Function Interfaces (FFI).


* **Dissemination Track Record:** Proven technical writing capability with a track record of contributing to peer-reviewed research publications and presenting work at national scientific or engineering conferences.


* **Soft Skills:** Advanced technical report writing skills, ability to influence other team members on code optimisation choices, and strong peer-collaboration capabilities.



### Additional Duties

* Undertake national or international travel to present peer-reviewed research work and software utilities at relevant scientific conferences and workshops.


* Deliver specialised internal training sessions on low-level performance profiling techniques, cache utilisation, or Python interface compilation for the broader engineering group.


* Deputise for senior team members in technical review boards or progress tracking meetings when required.
