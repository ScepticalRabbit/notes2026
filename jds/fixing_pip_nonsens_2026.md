# NOTES: Computational Experimental Design Engineer JDs

I want you to help me create a series of job descriptions for a new job family I am creating in our organisation. We have almost every type of engineer in my organisation from software, to electrical, to mechanical to civil. We also have research software engineers. This role has to be distinct and combine a unique set of capabilities because I have tried hiring before for these roles and it is hard enough to find a good software engineer who knows what memory alignment and a CPU cache is let alone having the skills I need in experimental design and sensor modelling/uncertainty quantification. 

The job family will be called: Computational Experimental Design Engineer with the following grades:

G - Senior Computational Experimental Design Engineer
H - Lead Computational Experimental Design Engineer
I - Principal Computational Experimental Design Engineer

The job needs a diverse set of skills spanning: experimental design, sensor uncertainty quantification, VVUQ - especially the mathematics of validation, software engineering (especially for performance aware programming, and making performant code available to other non-software engineers and experimentalists through python), the ability to translate mathematics into highly performant code and to develop new algorithms when needed (at higher levels). The purpose of the role is to create the software libraries that will be used by fusion engineers to design and analyse validation experiments for materials and components in extreme environments. The purpose of this software is to maximise the information gained from an optimised set of material and component tests allowing fusion engineers to make risk-aware decisions supported by thorough VVUQ. The set of skills required is unique because this role sits at the interface of the simulations required to design fusion components and the real world data needed to validate these simulations.
