# Abstract

Zig is a modern systems programming language built around simplicity, explicitness and low level control of the silicon. In this talk, we introduce Zig through Riley, a scientific rasteriser for synthetic imaging and uncertainty quantification. We follow Riley’s journey from Python to a high performance systems implementation, introducing key language concepts and the features that make Riley fast. Along the way, we offer two perspectives on Zig: one from an experienced systems programmer and one from a scientific Python user learning systems programming through Riley.
